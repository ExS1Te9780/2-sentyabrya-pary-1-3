# Мини-графический редактор

## 1. Что делает программа
Программа показывает работу трёх главных принципов ООП (инкапсуляция, наследование, полиморфизм). Она создаёт круги и квадраты, хранит их координаты и считает площадь каждой фигуры, а потом складывает все площади вместе.

## 2. Как устроена программа

**Инкапсуляция** – координаты фигур (x, y) скрыты от прямого доступа. Чтобы их получить или изменить, нужно использовать специальные методы get_coords() и set_coords().

**Наследование** – есть базовый класс Figure (фигура) и два дочерних: Circle (круг) и Square (квадрат). Круг добавляет радиус, квадрат добавляет длину стороны. Все общие свойства (координаты) хранятся в родительском классе.

**Полиморфизм** – у всех фигур есть метод calculate_area(), но каждый считает площадь по-своему (у круга по формуле πR², у квадрата – сторона²). В программе мы создаём список из разных фигур и в одном цикле вызываем у них этот метод, не думая о том, какой именно тип фигуры перед нами.

## 3. Пример использования

```python
# Создаём фигуры
circle = Circle(0, 0, 5)      # круг с центром (0,0) и радиусом 5
square = Square(10, 10, 4)    # квадрат с центром (10,10) и стороной 4

# Считаем площадь
print(circle.calculate_area())   # 78.54
print(square.calculate_area())   # 16.0

# Меняем координаты
circle.set_coords(1, 1)
print(circle.get_coords())       # (1, 1)

# Список фигур и общая площадь
shapes = [circle, square, Circle(2, 3, 2.5)]
total = 0
for shape in shapes:
    total += shape.calculate_area()
print(f"Общая площадь: {total}")
```
## 4. Что выводит программа

Circle площадь: 78.54
Square площадь: 16.00
Circle площадь: 19.63
Square площадь: 36.00
Circle площадь: 28.27

Общая площадь всех фигур: 178.44

Координаты первого круга (через геттер): (0, 0)
